## The five epics
- **SIM** — Simulator v2 (granular day-to-day, opportunity cost, market cycles, real-ERP digital twin)
- **BC** — Business-Case & RFQ Studio (questionnaire → financial model → Excel + PPTX + PDF)
- **FND** — Funds & Financing Advisory (catalog + 7-filter matching + de minimis + dossier + durability)
- **EXP** — Expertise & Mastery + Marketplace (ESCO → gap → path → verifiable credential → matching → expert-for-hire)
- **AI** — Self-Evolution & Autonomous Research (CORAL evolves scenarios; researchclaw/Feynman refresh funds/market data)

Conventions & Definition of Done

Applies to every story below. Points are effort (Fibonacci), read for a solo+AI cadence — not team velocity.

Conventions

Story IDs — DOC-{sprint}-{n}; ANAF tasks flagged amber
Branches — feature/DOC-xx-x-slug · bugfix/ · hotfix/
Commits — feat(module): … / fix(module): … · <50 lines where possible
Backend — NestJS, prefix /api/v1, Swagger at /api-docs
DB — PostgreSQL + Prisma; every table org-scoped (organizationId)
Frontend — Next.js 15 App Router, /[locale], next-intl RO/EN
PR gate — CI lint+test green · 1 review · comments resolved
Estimate scale — 1,2,3,5,8 pts; sprint target ≈ 20–26 pts of "Must"

Global Definition of Done

  • Code + unit tests, ≥80% coverage (≥90% on financial logic)
  • Swagger/OpenAPI updated for new/changed endpoints
  • Prisma migration is reversible + seed updated
  • RO/EN i18n keys for any user-facing text
  • ESLint + Prettier pass; TypeScript strict, no any
  • Immutable audit-log entry on every financial write
  • Org-scoped authZ verified (no cross-tenant leakage)
  • Deployed to staging; smoke-tested end-to-end
  • ANAF/compliance task ratified by romanian-tax-specialist ◆
  • Change logged to project-ledger

DOC-42-1Prisma schema + migration for CO entities5 pts

As the platform, I want the Controlling model persisted & org-scoped, so data survives restarts and is multi-tenant safe.

Data model (Prisma)
model CostCenter {
  id             String   @id @default(cuid())
  organizationId String
  code           String   // CC-1000
  name           String
  nameRo         String
  category       CostCenterCategory
  parentId       String?
  managerName    String?
  currency       String   @default("RON")
  active         Boolean  @default(true)
  costLines      CostLine[]
  createdAt      DateTime @default(now())
  @@unique([organizationId, code])
  @@index([organizationId])
}
model CostLine {
  id             String   @id @default(cuid())
  organizationId String
  costCenterId   String
  costElementId  String
  period         String   // 2026-07
  planned        Decimal  @db.Decimal(14,2)
  actual         Decimal  @db.Decimal(14,2)
  @@index([organizationId, period])
}
// + ProfitCenter, CostElement, InternalOrder, AllocationCycle, ProfitabilitySegment (same org-scoping)
Acceptance criteria
  • Migration applies + rolls back cleanly on a fresh DB
  • Seed script reproduces the demo org from the PoC
  • All money columns Decimal(14,2), never float
